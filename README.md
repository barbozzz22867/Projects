# Практическая работа №1. Декомпозиция программного проекта

**Цель:** научиться разделять большой программный проект на управляемые задачи.

---

## Исходная ситуация

Команда получила заказ на разработку системы управления задачами.

В системе должны быть реализованы:

- регистрация пользователей;
- авторизация;
- создание задач;
- редактирование задач;
- назначение исполнителей;
- изменение статусов;
- поиск задач;
- просмотр списка задач.

Руководитель проекта записал одну большую задачу: «Разработать систему управления задачами». Но команда не понимает, с чего начинать.

---
