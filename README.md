# Система складского учёта

Информационная система для управления товарными запасами. Разработана в рамках курса «Проектное управление» (RPO, группа 2). Реализована на базе файловой СУБД / LibreOffice Base.

## Команда проекта

| Роль | Участник | Ответственность |
| :--- | :--- | :--- |
| PM / DB Architect / Backend | Егор | Архитектура БД, серверная логика, планирование спринтов |
| Frontend / QA | [Имя участника] | Интерфейс LibreOffice Base, функциональное тестирование |
| Analyst / Documentation | [Имя участника] | Сбор требований, пользовательская документация |

## Функционал
- CRUD операции для товаров, поставщиков и категорий
- Нормализованная схема базы данных (3НФ)
- Формы ввода/редактирования с валидацией
- Отчётность по остаткам на складе

## Технологии
- СУБД: LibreOffice Base / SQLite / File-based DB
- Frontend: LibreOffice Forms / Python Tkinter
- Управление проектом: Git, Trello/Jira, RACI матрица

## Установка и запуск
1. Клонируйте репозиторий: `git clone https://github.com/your-repo.git`
2. Установите зависимости (если есть): `pip install -r requirements.txt`
3. Запустите приложение: `python main.py` или откройте `.odb` файл
